# Architecture summary

## Ownership

Public policy source, effective dates and version history. Only approved public material belongs here.

## Boundaries

This public repository owns approved policy source only. It does not own application code, private assessments or internal specifications. gatherkind-web will render approved policy versions through a publishing process that is still to be selected.

## First implementation

Establish the approval, versioning and publication process before publishing consumer policies.

## Verification

Run `git diff --check`. CI runs repository hygiene only. There are no application tests or runtime dependencies yet.
